# Thirst (Android and iOS app)

Thirst is a drinking card game for a group of friends. On your turn you get a few challenge cards, pick one and do it, or take 15 sips instead. The app is built with Vite, React, TypeScript, Tailwind and shadcn/ui, and packaged as a native Android and iOS app with [Capacitor](https://capacitorjs.com/).

The whole game is bundled inside the app, so it works fully offline and collects no data. It's available in English and French (switch in the Info tab, or on the welcome screen).

## Sharing the app with a friend (no app store needed)

Android phones can install an app straight from a file, so you don't need the Play Store to give the game to friends. Your friend does not need Claude, GitHub or a computer.

1. Build the app file (see "Building the APK" below), or use the latest `Thirst-x.y.z.apk` you already have.
2. Upload that `.apk` file to Google Drive, then use **Share > General access > Anyone with the link** and copy the link.
3. Send your friend the link together with the steps in [INSTALL-ANDROID.md](INSTALL-ANDROID.md) (there's an English and a French version you can paste into a message).

To send an update later, build a new APK with a higher version number and share it the same way. Installing it over the old one keeps their saved game, presets and custom cards.

iPhones can't install apps from a file. For an iPhone friend the options are TestFlight (needs an Apple Developer account at $99 a year and a Mac to build) or the App Store.

## What's in the app

- **Play tab**: a home screen with "Continue" for a saved game, "New game", and up to 3 saved presets. A new game is two short steps (packs, then players), with rules like cards per turn and number of rounds behind an Options button.
- **During a game**: an "It's your turn" screen for each player, cards whose text sizes itself to fill the screen, a focus view when you pick a card (with Undo and Done), a cheers animation when someone takes the sips, a history panel with everyone's sips and cards, and "Undo last turn".
- **Cards that name players**: some cards pick a player by name. The choice favours people who have been picked less and never picks the player whose turn it is.
- **Who likes who**: when the Flirty pack is on, an optional switch lets you say what each player is (man, woman, neutral) and who they're into (men, women, both, no one). Flirty cards then pick someone the current player is into, ideally someone who's into them too. Anything left blank counts as open to anyone.
- **Custom cards with logic**: the card creator can drop a [random player] or [someone they're into] into the text, and the game fills in a name when the card comes up.
- **Cards tab**: every card by pack, with a pinned pack filter, and your own custom cards.
- **Info tab**: rules, card types, language, haptics, clear data, and a Buy Me a Coffee link.
- **Native touches**: offline fonts, notch and status bar handling, no zoom or text selection, Android back button support, haptics, a splash screen, and a game that survives the app being closed.

| `src/` | The app (React + TypeScript) |

```bash
npm install          # once

npm test             # tests (translations, targeting, game flow, undo)
npm run lint
```

## Building the APK

```bash
npm run build
npx cap sync
cd android
./gradlew assembleDebug
```

The file appears at `android/app/build/outputs/apk/debug/app-debug.apk`. Rename it to something like `Thirst-1.3.1.apk` before sharing it.

On Windows the Android build needs a JDK, and Android Studio's own one works: set `JAVA_HOME` to `C:\Program Files\Android\Android Studio\jbr`. `android/local.properties` must point at the Android SDK (Android Studio creates it).

This is a debug build, which is fine for friends. It is signed with the debug key stored on the computer that built it, so keep building updates on the same computer, otherwise friends have to uninstall the old version before installing the new one.

## Changing the icon

Edit the SVG in `assets/make-assets.mjs` (and the matching `LogoMark` in `src/components/Logo.tsx`), then run:

```bash
node assets/make-assets.mjs
npx capacitor-assets generate --android --ios
```

## Versioning

Bump the version for every build you share or publish:

- **Android:** `versionCode` (whole number, +1 each time) and `versionName` in `android/app/build.gradle`
- **iOS:** `MARKETING_VERSION` and `CURRENT_PROJECT_VERSION` (Xcode: App target > General)
- `version` in `package.json` and `APP_VERSION` in `src/screens/InfoScreen.tsx`

## Publishing to Google Play

```bash
npm run build && npx cap sync android
npx cap open android
```

In Android Studio:

1. Create a signing key once with *Build > Generate Signed App Bundle > Create new keystore*. Back up the keystore file and both passwords somewhere safe, because losing them means you can never update the app again.
2. Build a signed App Bundle (`.aab`) with *Build > Generate Signed App Bundle*.
3. In the [Play Console](https://play.google.com/console) ($25 once), create the app "Thirst", fill in the listing (description, screenshots, privacy policy URL), upload the `.aab`, complete the content rating questionnaire (declare alcohol references and expect an 18+ rating) and the data safety form (the app collects no data), then submit for review.

Friends who installed the sideloaded debug APK will need to uninstall it once before installing the Play Store version, because the two are signed with different keys.

## Publishing to the App Store

On a Mac with Xcode and an [Apple Developer account](https://developer.apple.com/programs/) ($99 a year):

```bash
npm install && npm run build && npx cap sync ios
npx cap open ios
```

In Xcode, pick your team under *Signing & Capabilities*, choose *Any iOS Device*, then *Product > Archive* and *Distribute App > App Store Connect*. In [App Store Connect](https://appstoreconnect.apple.com/), create the app "Thirst" with bundle ID `app.thirst.mobile`, set the age rating to 17+ for alcohol references, attach the build and submit.

## Notes for store review

- **No real money:** Thirst is a party game with no money, bets or prizes. Say so clearly in both store descriptions so reviewers don't treat "drinking card game" as gambling.
- **Alcohol:** both stores allow it with the right age rating. The app already shows a "drink responsibly" note.
- **Privacy policy:** both stores require a link even though the app collects nothing. A short page saying that all data stays on the device is enough (GitHub Pages works).
